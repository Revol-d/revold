# Código de conduta

Este código vale para todo espaço do projeto **revold**: repositório, issues, pull requests,
revisões de código e os canais em que o time conversa sobre o projeto.

## O que esperamos

- **Respeito.** Critique o código, a decisão ou o argumento, nunca a pessoa. Divergência técnica é
  saudável e esperada; ataque pessoal, não.
- **Boa-fé.** Presuma que quem abriu o PR ou a issue está tentando ajudar. Pergunte antes de acusar.
- **Clareza e paciência.** Explique o porquê, não só o quê. Nem todo mundo tem o mesmo contexto, e
  parte do trabalho é registrar esse contexto (na KB, na descrição do PR) para o próximo.
- **Responsabilidade.** Se você quebrou algo ou errou, avise cedo. Errar faz parte; esconder, não.

## O que não toleramos

- Assédio, intimidação ou linguagem depreciativa de qualquer natureza.
- Comentários discriminatórios por gênero, raça, orientação, religião, deficiência, idade ou
  qualquer outra característica pessoal.
- Exposição de informação privada de outra pessoa sem consentimento.
- Comportamento persistente que atrapalhe o trabalho ou a convivência do time.

## Aplicação

Quem observar ou sofrer uma violação deste código deve reportar **em privado** a um dos donos do
repositório, `@SamuelSMatos` ou `@dmourans`. Os relatos são tratados com discrição.

Os mantenedores são responsáveis por esclarecer os padrões de comportamento e podem tomar as ações
que julgarem apropriadas e justas diante de um comportamento inaceitável, de uma conversa privada
à remoção do acesso, conforme a gravidade.
